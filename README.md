# Pathemu – Prototipo

Prototipo navigabile dell'app per creare itinerari condivisi con gruppi di amici (mappa, schede dal basso, pagine gruppi).

## Struttura
- `index.html` – markup
- `css/style.css` – stili e animazioni
- `js/app.js` – logica, dati di esempio e navigazione

## Avvio
Apri `index.html` nel browser (vista mobile dagli strumenti sviluppatore per l'effetto app).
Font da Google Fonts: serve connessione.

## GitHub Pages
Settings → Pages → Branch `main` / root → Save.
